# Image credits

Images in `src/assets/` are either generated neutral placeholders or AI-generated photos (fictional
people and places, no third-party photos). Each AI-generated file has its generation prompt embedded
in its metadata (stripped from the published output).

When a stock photo (Unsplash, Pexels) replaces a placeholder, add it here **and** set the `credit`
field on that image in the collection or in `src/config/site.ts`.
